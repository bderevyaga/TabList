# TabList

Chrome Extension для сохранения, открытия и управления списком ссылок из popup-окна.

## Возможности

- Сохранение списка URL в `chrome.storage.local` с автосохранением.
- Быстрый захват открытых вкладок (`Capture Tabs`).
- Regex-фильтр для `Capture Tabs` только по URL вкладки.
- Открытие ссылок из списка пакетами (`Open Links`).
- Закрытие неактивных вкладок, которые есть в списке (`Close Listed`).
- Копирование и очистка списка ссылок.
- Дедупликация URL в интерфейсе и при операциях с вкладками.

## Требования

- Google Chrome (или Chromium-совместимый браузер с поддержкой Manifest V3).

## Установка (локально)

1. Откройте `chrome://extensions`.
2. Включите **Developer mode**.
3. Нажмите **Load unpacked**.
4. Выберите папку проекта `TabList`.

После этого расширение появится в панели браузера.

## Использование

1. Нажмите на иконку расширения, чтобы открыть popup.
2. (Опционально) заполните поле **Capture Filter** регулярным выражением, чтобы захватывать только вкладки с URL, который ему соответствует.
3. Вставьте URL (по одному на строку) или нажмите **Capture Tabs**.
4. Используйте:
   - **Open Links**: открыть ссылки из списка.
   - **Close Listed**: закрыть неактивные вкладки, URL которых есть в списке.
   - **Copy**: скопировать текущий список.
   - **Clear**: очистить список и хранилище.

## Права расширения

- `storage`: хранение списка ссылок между сессиями.
- `tabs`: чтение открытых вкладок, создание и закрытие вкладок.

## Структура проекта

- `manifest.json` — конфигурация расширения (Manifest V3).
- `popup.html` — разметка popup.
- `popup.css` — стили popup.
- `popup/main.js` — точка входа popup.
- `popup/parsers/` — парсинг URL и regex-фильтра.
- `popup/controllers/` — UI-контроллер popup.
- `popup/services/` — работа с вкладками браузера.
- `popup/storage/` — обертка над `chrome.storage.local`.
- `popup/view/` — доступ к DOM-элементам popup.
- `popup/utils/` — утилиты (clipboard, delay).
- `icons/` — иконки расширения.
